# 🐍 贪吃蛇模拟

一个**零依赖、单文件**的贪吃蛇游戏：全部 HTML / CSS / JavaScript 都内嵌在 `index.html` 里，没有任何外部资源、库或构建步骤。

- ✅ 双击即玩：下载后直接双击 `index.html`，任意现代浏览器（桌面 / 手机 / 平板）都能跑
- ✅ 可部署到任何静态托管（GitHub Pages、Gitee Pages、Vercel……），得到一个链接分享给别人，点开即玩
- ✅ 无需网络、无需安装、无需打包

## 🎮 玩法

### 规则与计分

- 用方向键操控蛇吃到食物即可成长并得分
- 每吃一个食物 **+10 × 当前速度档** 分
- 每吃 3 个食物，速度提升一档（共 9 档：起步每秒 7 格，最快每秒 15 格）
- 撞到墙壁 / 障碍物 / 自己的身体即游戏结束（「穿墙环绕」模式下撞墙会从对面出现）

### 操作

| 动作 | 桌面 | 触屏 |
|---|---|---|
| 移动 | 方向键 / WASD | 在画布上滑动，或使用屏幕下方的虚拟方向键 |
| 暂停 / 继续 | `空格` 或 `P` | 右上角 ⏸ 按钮 |
| 开始 / 再来一局 | `空格` / `回车` | 点击按钮 |

切到后台（或切走浏览器标签页）会自动暂停，回来继续，不会白死。

### 模式设置

开局前可在菜单里选择（一局内固定，需要换模式就回主菜单）：

- **墙壁**：撞墙即死 / 穿墙环绕
- **障碍物**：无障碍 / 随机生成 14 块石头（障碍互不相邻、不会贴脸出生点）

### 最高分

最高分按「墙壁模式 × 障碍物」的难度组合**分开记录**，存放在浏览器本地（`localStorage`），换难度不混榜；刷新页面后仍然保留。

## 🚀 如何部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（设为 Public），把 `index.html`（以及本 README）上传到仓库根目录
   > ⚠️ 文件名必须保持 `index.html`——访问目录地址时服务器会默认返回它，这样别人访问仓库主页就能直接开玩
2. 仓库 **Settings → Pages → Source** 选择 `Deploy from a branch`，分支选 `main`，保存
3. 等待一两分钟，访问：

   ```
   https://<你的用户名>.github.io/<仓库名>/
   ```

   （例如用户名 `alice`、仓库名 `snake`，地址就是 `https://alice.github.io/snake/`）

拿到链接后发给别人，手机电脑点开即玩。后续每次更新 `index.html` 并推送，线上会自动同步。

## 💻 本地运行

最简单的办法：**双击 `index.html`**，直接在浏览器里打开就能玩。

个别浏览器（例如开启严格隐私模式的 Safari）会限制 `file://` 协议下的本地存储，导致最高分无法持久化；如果遇到这种情况，可以用任意静态服务器打开，例如：

```bash
# Python 3
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080/
```

## 🔧 技术细节

- **纯前端单文件**：无外部依赖、无网络请求、无构建步骤，`file://` 下即可运行
- **Canvas 2D 渲染 + 固定时间步逻辑 + 帧间插值**：蛇身平滑滑动而非逐格跳动，加速后依然丝滑；高分屏按 `devicePixelRatio` 适配不模糊
- **Web Audio 合成音效**：吃食物 / 开局 / 死亡音效全部由代码生成，无需音频文件，首次交互后才播放（符合浏览器自动播放策略），可一键静音
- **输入队列**：方向键缓冲最多 2 步，避免快速连按导致 180° 掉头自杀
- 装饰：蛇身渐变 + 辉光、食物呼吸脉动、吃食物粒子特效与飘分、死亡逐节褪色动画

## 🧩 兼容性

Chrome / Edge / Firefox / Safari（含 iOS / Android 移动端浏览器）的近期版本均可运行；触屏设备自动出现虚拟方向键与滑动手势支持。
